# Vital Link Journal

This project initializes a small command-line journal application that stores entries in `vital_link_journal.txt`.

## Run it

```bash
python journal.py --help
python journal.py add "My first journal entry"
python journal.py list
python journal.py search "first"
```

## Files

- `journal.py` — command-line journal app
- `vital_link_journal.txt` — journal storage file
